React Native Spy — theme directions

Six visual directions for the same redesigned UI. Every preview below is the live mockup running in an iframe, not a screenshot — they share one base.css and one harness.js, so the layout, data and behaviour are byte-identical across all six. Only the design tokens differ. That means what you are comparing is visual language alone.

Preview scale Open any theme full-screen to actually use it

What each mockup demonstrates live: real fixed-height row virtualization (scroll the request list — the status bar shows how many rows are actually in the DOM out of 60), the new-row arrival flash, distinct hover / selected / focus states, skeleton loading on first paint, a streaming console with sticky-bottom tailing plus a “N new” pill when you scroll away, and a real timing bar driven by actual duration.

Keyboard: click the request list, then ↑ ↓ PgUp PgDn Home End to move the active row and Enter to open it. ← → move between panel tabs. Tab reaches every control, and focus is always visible — none of which is currently true in the app.
